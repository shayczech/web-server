    Why API Gateway, not a Lambda Function URL: Function URLs were tried first — both AuthType=AWS_IAM behind CloudFront's Origin Access Control, and AuthType=NONE with an explicit public resource policy. Both were rejected with a hard AccessDeniedException at the Lambda invoke layer itself, confirmed against a disposable from-scratch probe function with no other configuration. API Gateway sidesteps whatever that restriction is. Migrated off a VPC + ALB + Auto Scaling Group + EC2 + NAT Gateway architecture (~$64/mo) to this one (~$2–5/mo) in September 2026 — same site, same /api/stats behavior, no servers left to patch.
